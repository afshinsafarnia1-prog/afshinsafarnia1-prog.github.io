# فعال‌سازی یک‌بارهٔ ترجمهٔ خودکار RADYAD

## چه چیزی خودکار می‌شود؟

- متن‌های ثابت HTML، عنوان و توضیحات صفحات، برچسب‌ها، placeholderها و متن‌های دسترس‌پذیری اسکن می‌شوند.
- رشته‌های فارسیِ نوشته‌شده در فایل‌های JavaScript، از جمله پیام‌های خطا، موفقیت، وضعیت، فرم‌ها و پیام‌های پویای رابط کاربری، به هفت زبان دیگر ترجمه می‌شوند.
- محتوای چهار مقالهٔ باقی‌مانده و سند قوانین از مسیر ترجمهٔ HTML با حفظ ساختار و فراداده تولید می‌شود.
- ترجمه‌ها بر اساس متن مبدأ ذخیره می‌شوند؛ در تغییرهای بعدی، رشته‌های بدون تغییر دوباره به سرویس ارسال نمی‌شوند.
- مرورگر فقط فایل زبان انتخاب‌شده را بارگذاری می‌کند و با تغییر زبان، متن اصلی فارسی قابل بازیابی است.

## تنها تنظیم لازم

1. در Google Cloud Console یک پروژه انتخاب یا ایجاد کنید و Cloud Translation API را فعال کنید.
2. یک API key بسازید و آن را فقط برای Cloud Translation محدود کنید. کلید در مرورگر یا مخزن کد قرار نمی‌گیرد.
3. در مخزن GitHub، به Settings → Secrets and variables → Actions → New repository secret بروید.
4. نام secret را دقیقاً GOOGLE_TRANSLATE_API_KEY بگذارید و کلید را در مقدار آن وارد کنید. کلید را در چت یا در فایل‌های مخزن ارسال نکنید.
5. در GitHub، بخش Actions را باز کنید، workflow با نام Generate RADYAD machine translations را انتخاب کنید و یک بار روی شاخهٔ feature/full-site-i18n اجرا کنید.

پس از این تنظیم یک‌باره، تغییر در فایل‌های HTML یا JavaScript روی شاخهٔ فعال به‌طور خودکار ترجمه‌ها را به‌روزرسانی می‌کند. پس از ادغام مجاز این PR به شاخهٔ main، همین workflow روی main نیز اجرا می‌شود.

## هزینه و کنترل

برآورد فعلی برای ترجمهٔ اولیهٔ محتوای ثابت و رابط کاربری حدود ۱٫۲۷ میلیون کاراکتر ورودی در هفت زبان است. طبق تعرفهٔ رسمی Google Cloud، ۵۰۰ هزار کاراکتر نخست در هر ماه رایگان است و پس از آن نرخ مدل NMT برابر ۲۰ دلار به‌ازای هر یک میلیون کاراکتر است؛ بنابراین هزینهٔ اولیه، در صورت استفاده‌نشدن سهمیهٔ رایگان ماهانه، حدود ۱۵ تا ۱۶ دلار برآورد می‌شود. مقدار نهایی به مصرف همان پروژه در آن ماه بستگی دارد.

برای جلوگیری از هزینهٔ ناخواسته، اسکریپت سقف کاراکتر برای هر اجرا دارد و پیش از هر درخواست، برآورد را بررسی می‌کند. می‌توانید در Google Cloud برای پروژه سقف بودجه و هشدار مصرف تنظیم کنید؛ هشدار بودجه به‌تنهایی سقف سخت هزینه نیست.

## حریم خصوصی و بازبینی

ترجمه‌گر فقط متن‌های ثابت مخزن و رشته‌های نوشته‌شده در کد را می‌فرستد. پیام‌های خصوصی کاربران، متن پرونده‌ها، معرفی و زندگی‌نامهٔ درمانگران، محتوای ارسالی درمانگران و فیلدهای قابل ویرایش کاربر به سرویس ترجمه ارسال نمی‌شوند و در زبان اصلی نمایش داده می‌شوند.

ترجمهٔ ماشینی جای بازبینی تخصصی را نمی‌گیرد. متن‌های حقوقی، رضایت آگاهانه، بحران و محتوای بالینی باید پیش از استفادهٔ رسمی توسط فرد واجد صلاحیت بازبینی شوند.
