# فعال‌سازی یک‌بارهٔ ترجمهٔ خودکار RADYAD

## چه چیزی خودکار می‌شود؟

- متن‌های ثابت HTML، عنوان و توضیحات صفحات، برچسب‌ها، placeholderها و متن‌های دسترس‌پذیری اسکن می‌شوند.
- رشته‌های فارسیِ نوشته‌شده در فایل‌های JavaScript، از جمله پیام‌های خطا، موفقیت، وضعیت، فرم‌ها و پیام‌های پویای رابط کاربری، به هفت زبان دیگر ترجمه می‌شوند.
- محتوای مقاله‌ها و سند قوانین از مسیر ترجمهٔ HTML با حفظ ساختار و فراداده تولید می‌شود.
- ترجمه‌ها بر اساس متن مبدأ ذخیره می‌شوند؛ در تغییرهای بعدی، رشته‌های بدون تغییر دوباره به سرویس ارسال نمی‌شوند.
- مرورگر فقط فایل زبان انتخاب‌شده را بارگذاری می‌کند و با تغییر زبان، متن اصلی فارسی قابل بازیابی است.

## تنها تنظیم لازم

1. در Google Cloud Console یک پروژه انتخاب یا ایجاد کنید و Cloud Translation API را فعال کنید.
2. یک API key بسازید و آن را فقط برای Cloud Translation محدود کنید. کلید در مرورگر یا مخزن کد قرار نمی‌گیرد.
3. در مخزن GitHub، به Settings → Secrets and variables → Actions → New repository secret بروید.
4. نام secret را دقیقاً GOOGLE_TRANSLATE_API_KEY بگذارید و کلید را در مقدار آن وارد کنید. کلید را در چت یا در فایل‌های مخزن ارسال نکنید.
5. پس از ادغام مجاز PR به شاخهٔ اصلی، workflow ماهانه به‌طور خودکار اجرا می‌شود. پیش از آن، می‌توان workflow را دستی روی شاخهٔ feature اجرا کرد.

## برنامهٔ رایگان سه‌ماهه

- سقف داخلی ترجمه‌گر روی **۴۵۰٬۰۰۰ کاراکتر در هر ماه** تنظیم شده است.
- بودجهٔ مصرف در فایل `auto-translations/monthly-budget.json` ثبت می‌شود و بین ترجمهٔ مقاله‌ها و رابط کاربری مشترک است. مرز ماه بر اساس منطقهٔ زمانی اقیانوس آرام (هم‌راستا با چرخهٔ ماهانهٔ Google) محاسبه می‌شود؛ اگر فایل بودجه خراب یا ناخوانا باشد، ترجمه برای جلوگیری از عبور از سقف متوقف می‌شود.
- هر درخواست پیش از ارسال از بودجه کم می‌شود؛ اگر بودجهٔ ماه تمام شود، ترجمه متوقف می‌شود و باقی کار برای ماه بعد می‌ماند.
- فایل‌های ترجمه به‌صورت مرحله‌ای ذخیره می‌شوند؛ ماه بعد فقط بخش‌های باقی‌مانده ترجمه می‌شوند.
- workflow در روز اول هر ماه، پس از نیمه‌شب به وقت اقیانوس آرام اجرا می‌شود و تغییرهای جدید در HTML و JavaScript نیز با همان سقف ماهانه وارد صف می‌شوند.
- برآورد فعلی حدود ۱٫۲۷ میلیون کاراکتر در مجموع هفت زبان است؛ ۴۵۰ هزار کاراکتر در ماه، در صورت ثابت ماندن برآورد، برای تکمیل آن طی حدود سه ماه کافی است.

Google Cloud برای ترجمهٔ متنی NMT، مجموعاً ۵۰۰ هزار کاراکتر در ماه را در سطح حساب رایگان می‌کند؛ Basic و Advanced در این سهمیه مشترک‌اند. بنابراین سقف ۴۵۰ هزار تایی ۵۰ هزار کاراکتر حاشیه می‌گذارد. رایگان ماندن قطعی است فقط اگر مصرف دیگر سرویس‌های ترجمه در همان حساب از این حاشیه عبور نکند. سهمیهٔ استفاده‌نشده به ماه بعد منتقل نمی‌شود. تعرفهٔ رسمی: https://cloud.google.com/products/translate/pricing

## حریم خصوصی و بازبینی

ترجمه‌گر فقط متن‌های ثابت مخزن و رشته‌های نوشته‌شده در کد را می‌فرستد. پیام‌های خصوصی کاربران، متن پرونده‌ها، معرفی و زندگی‌نامهٔ درمانگران، محتوای ارسالی درمانگران و فیلدهای قابل ویرایش کاربر به سرویس ترجمه ارسال نمی‌شوند و در زبان اصلی نمایش داده می‌شوند.

ترجمهٔ ماشینی جای بازبینی تخصصی را نمی‌گیرد. متن‌های حقوقی، رضایت آگاهانه، بحران و محتوای بالینی باید پیش از استفادهٔ رسمی توسط فرد واجد صلاحیت بازبینی شوند.
